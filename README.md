# BOBROS Vercel Site

Hand-drawn landing page inspired by the supplied Billionaire Bobo Club mockup.

## Local start

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel

1. Push this folder to GitHub.
2. Import the repo in Vercel.
3. Framework preset: Next.js.
4. Build command: `npm run build`.
5. Output directory: leave empty/default.

## Fast edits

Main content: `app/page.tsx`  
Visual style: `app/globals.css`
